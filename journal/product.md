# Product context

PandaOS is Marushan's private, cross-platform interface for running and monitoring coding agents. The repository README describes one interface for Claude Code, Codex, Copilot, OpenCode, Pi, Antigravity, and Muse Code. PandaOS is a fork of Paseo; preserve upstream behavior and the quiet, spacious app design described in `docs/design.md`.

Current work integrates the implemented changes from concurrent sessions into main. Keep agent history and open sessions intact, preserve cross-platform input behavior, and verify the combined interface before delivery. The [integration report](2026-10-14-main-integration.md) owns source inventory, verification and deployment limits. Recovery remains covered by its [implementation journal](2026-10-09-recovery-automatic.md).
